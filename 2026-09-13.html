Modenesi B, Lin JL, Kaphingst KA, Zhu A, Wheeler M, Zhang P, Fagerlin A. Prompting is not enough: supervised baselines and leakage control for measuring shared decision-making with LLMs in pediatric encounters. arXiv preprint. 2026 Aug 14. arXiv:2608.14792
https://arxiv.org/abs/2608.14792
Overview: Follow-up requested 2026-08-26. Full text read end to end (arXiv v1 — no revision exists). It answers two of the three deep-dive questions and explicitly declines the third. 21 audio-recorded paediatric surgical decision encounters, 19 patients, 7,566 utterance segments, 12 shared-decision-making behaviours. Arms: zero-shot Qwen 2.5 32B (4-bit, local, temperature 0); supervised logistic regressions over frozen Qwen3 embeddings; a logistic stack of both. Task type: classification, interpretive signal, multi-label · LLM: Qwen 2.5 32B, local, zero-shot · Setting: paediatric outpatient surgery · Volume: 7,566 segments / 19 patients · Human review: trained coders, macro κ 0.695 (per behaviour 0.41–0.83) Evidence weight: Single site, 19 patients, arXiv v1, no peer review, no external test set. The evaluation protocol is unusually careful for the size.
Eval question: Three deep-dive questions: (1) the full leakage taxonomy, (2) whether the supervised baseline survives a frontier model, (3) whether there is a clean mitigation worth a standing rule.
Methodology: • 19 patient-grouped outer folds (leave-one-patient-out) • Inner 5-fold patient-grouped cross-fitting; stacker weights and per-behaviour thresholds (0.05–0.95) fitted only on out-of-fold predictions • Cluster bootstrap resampling PATIENTS — 1,000 draws for marginal CIs, 5,000 for paired differences • Descriptive learning curve over patient subsamples (6–18 patients, 3 replicates each)
Measurement: Macro Cohen's κ pooled over outer folds, with patient-cluster CIs; paired Δκ with its own CI. Human–human macro κ 0.695 reported as CONTEXT, explicitly not as a ceiling, because the model target is the union of coder labels while the human figure compares two coders — different reference constructions.
Key findings: • (1) THREE leakage paths, not two: sibling recordings (2 patients contributed 2 recordings each); exemplar leakage — excluding the held-out recording still admitted the sibling recording (fired for 3 of 21 recordings); outer-fold leakage through a PRECOMPUTED PROMPT CACHE — for 3 of 19 outer folds, labelled exemplars from the outer held-out patient had entered cached predictions later used to fit the stacker. The affected few-shot results were excluded from the primary analysis. No per-path effect size is given. • (2) Frontier question NOT answered: one quantised open model, one prompt family. The authors decline any general LLM-vs-supervised ranking. • (3) Clean mitigation stated: every labelled artefact used to build features — prompt exemplars AND cached LLM outputs — must be generated inside the appropriate outer fold; report patient counts beside recording counts. • New in the full text: 'patient self-efficacy' has 126 labelled segments but only 10 contiguous spans across 6 patients — κ ≈ 0 for every approach despite human κ 0.764. The segment count overstates the independent evidence. • Zero-shot was not uniformly worse: it beat the supervised model on 'definition of option' (0.302 vs 0.198). • The authors state the CIs do not include uncertainty from choosing the model and prompt on this same corpus.
Soft spots: Still v1 and unreviewed. 19 patients, no external test set. The union reference favours sensitivity and is not an adjudicated consensus. No per-behaviour CIs. The leakage paths are identified but not quantified. The frontier-model question stays open.
Strengths: Treats the evaluation protocol as part of the method. Reports its own failures, including a behaviour it could not measure. Refuses to call human κ a ceiling when the reference constructions differ — a distinction almost no paper makes.
Relevance: Layer 1: classification (interpretive), and any few-shot pipeline. Layer 2: (a) /optimize — the direct hit. Cases used to pick few-shot examples, tune thresholds or iterate a prompt must not be the cases that measure the gate, and cached model outputs reused across evaluation rounds count as leakage too. Candidate standing rule for Prompt_Optimization_Guide.md. (b) Unit of analysis: the 126-segments-but-10-spans finding is the same problem as POPC's 100 cases = 75 patients — count independent units, not rows. (c) Consultation Quality / Missed Consultation Alert: a cheap supervised baseline remains the missing comparator.
Verdict reasoning: The follow-up delivered what it was for. The leakage taxonomy grew from two paths to three, and the third (the prompt cache) is the one most likely to occur in /optimize. The mitigation is stated cleanly enough to become a rule. Import: the three paths, the inside-the-fold rule, and the count-independent-units point. Quarantine: every κ value. It is one small corpus, and the frontier question was never tested.

Aldis R, Wang S, Sage M, Metzmaker M, Galvin H. Performance of an Ambient Generative AI Documentation Tool in a Linguistically Diverse Clinical Setting. medRxiv preprint. 2026 Aug 17. doi:10.64898/2026.08.14.26360467
https://www.medrxiv.org/content/10.64898/2026.08.14.26360467v1.full-text
Overview: Follow-up requested 2026-08-26. The medRxiv full text was reachable this time and was read end to end. Cambridge Health Alliance: a safety-net system serving about 140,000 patients a year, where over half speak a language other than English at home. 54,160 outpatient encounters, March 2024 – August 2025. English 72.9%, Portuguese 11.8%, Spanish 8.4%, Haitian Creole 4.3%. An interpreter was present in 23.1% of encounters and a certified bilingual provider in 4.0%. The tool generates an English note from encounters in 28 languages. Task type: summarization / ambient documentation · LLM system: Abridge (ASR + diarization + LLM pipeline) · Setting: outpatient, US safety-net · Volume: 54,160 encounters · Human review: provider editing is the instrument Evidence weight: Large, real-world and retrospective. One system and one vendor. Preprint.
Eval question: Three deep-dive questions: (1) are individual languages separable from the 'non-English' bucket, (2) is there any accuracy or safety endpoint behind the edit-rate proxy, (3) what is the tool?
Methodology: • Retrospective cross-sectional cohort • Outcome = Percent Effort Reduction (PER): vendor-reported % of final-note words generated by the tool and kept as-is (HPI + assessment/plan, word-weighted), dichotomised at ≥80% per the VENDOR's operational benchmark • GEE, binomial logit, exchangeable correlation within patient • Within-language bilingual-vs-interpreter Wald contrasts; omnibus Type III interaction test
Measurement: Odds ratios with 95% CIs from GEE.
Key findings: • (1) YES, separable, and the gap is consistent: Spanish OR 0.76 (0.71–0.81), Portuguese 0.79 (0.74–0.83), Haitian Creole 0.75 (0.69–0.82). Unadjusted ≥80 PER: English 57.6%, Spanish 51.1%, Portuguese 51.0%, Haitian Creole 50.5%, other 48.7%. A language of lesser diffusion performed like the major ones. • (2) NO accuracy or safety endpoint exists behind the proxy. The authors name PDQI-9 as future work. • (3) The tool is Abridge — whose own engineering blogs are already in the KB as PB-01/PB-02. • Bilingual provider vs interpreter within language: Spanish 0.91 (0.79–1.06), Portuguese 1.21 (0.82–1.79), Haitian Creole 1.00 (0.83–1.21), other 1.00 (0.49–2.05). Not significant, but several intervals are too wide to call a true null. • ⚠️ CORRECTION TO THE PARENT CARD: '21–25% less likely' is the authors' wording for an ODDS ratio of 0.75–0.79. With the outcome near 55%, odds and probability diverge. The absolute gap is about 6.5–9 percentage points (57.6% vs 48.7–51.1%), a risk ratio of about 0.85–0.89 — roughly 11–15% less likely, not 21–25%. The parent card repeated the misstatement.
Soft spots: The measurer is the producer: vendor-defined metric, vendor-defined threshold, and outcome data delivered by the vendor in weekly files. Android encounters were excluded because only iOS was EHR-integrated. Use was voluntary for providers and patients. No adjustment for specialty, visit complexity, acoustic environment or individual editing habits. PER mixes tool quality with how hard a provider edits. The pipeline has three layers (ASR, diarization, LLM), and the gap cannot be assigned to any one of them.
Strengths: Scale, a real safety-net population, a per-language breakdown, and clustering handled correctly. The full text makes its own limitations explicit.
Relevance: Layer 1: summarization / documentation. Layer 2: KTP #12 gains its largest anchor — scoped as 'language is an axis that must be measured, and edit rate by language is a cheap monitoring signal', not as an effect size. KTP #14 (evaluate the layers): here is a gap nobody can locate because only the end-to-end output was measured. Producer ≠ measurer (the Panel design): a vendor-supplied metric is not an independent endpoint. Statistician_Guide.md: a clean teaching example of odds-ratio-read-as-risk-ratio when the outcome is common.
Verdict reasoning: The deep-dive answered all three questions and found a reporting error the parent card had inherited. Import: the language axis, the per-language consistency, and stratified edit rate as a monitoring instrument — each with the vendor-metric caveat attached. Cite the gap only as OR 0.75–0.79 or about 6.5–9 absolute points. Never as '21–25% less likely'.

Fox S, Markham L, Lail R, Karotsieris M. LLM Judges Verify Presence, Not Absence: Omission Blindness in AI Clinical Notes and What Recovers It. arXiv preprint. 2026 Aug 31. arXiv:2608.31016
https://arxiv.org/abs/2608.31016
Overview: Asks whether the standard safety check for AI-drafted clinical notes — an LLM judge reading the note against the transcript — can detect omissions. Builds a benchmark of 500 single-error note pairs from audited fact sheets: 298 with a named fact certainly absent, 202 added-or-altered controls. Tests eight judge designs using paired discrimination (does the flawed note score below its clean twin; 0.5 = coin flip). Authors are from Composo, an evaluation-tooling company. The conflict is disclosed, and the measurement path does not use their product. Task type: LLM-as-judge for summarization / documentation · LLM system: eight judge designs, frontier models · Signal type: explicit (fact present / absent) · Setting: ambient-scribe notes (benchmark + real vendor notes) · Clinician involvement: physician author validated 70 items; a second, non-author clinician graded the severity rubric blind Evidence weight: arXiv preprint, not peer reviewed. Constructed single-error benchmark plus a transfer test on real vendor notes. Vendor-of-evaluation-tooling authors.
Eval question: Can an LLM judge detect what a note leaves out — and if not, what recovers it?
Methodology: • Paired single-error twins isolate the construct (omission vs addition/alteration) • Eight judge designs; wording changes, voting and GEPA prompt optimisation all tested as fixes • Task restructured: enumerate the facts the transcript establishes, then check the note for each — as (a) a per-fact pipeline and (b) a GEPA-evolved single-call prompt • Threshold transfer tested on real notes from the companion census (PQ-192)
Measurement: Paired discrimination (0.5 = chance); detection rate at a stated false-alarm rate; physician adjudication of disagreements.
Key findings: • Paired discrimination 0.79–0.94 on added or altered content, but 0.50–0.63 on OMISSIONS — near chance • On single notes, no design flags omissions reliably more often than it flags perfect notes • Wording changes, voting and GEPA prompt optimisation move the operating point without creating detection • Restructuring recovers it: per-fact pipeline at 2.7% false alarms; single call detects more (36.9% vs 24.6%, p=0.002) at 6.2% false alarms and a tenth of the cost • Physician sided with the pipeline 10 of 10 times where the two routes disagreed (p=0.002) • No benchmark threshold transferred to real vendor notes — recalibration was required • Omissions whose fact is restated elsewhere in the note defeat both routes
Soft spots: Constructed benchmark with one error per note — real notes carry several. Even the recovered detection rate is only about 37%: an improvement, not a solution. The physician validator is an author. English only. GEPA optimisation was run against the same benchmark it is evaluated on. Unreviewed.
Strengths: The twin design isolates exactly one construct. It tests the obvious fixes and reports that they fail. It offers a mechanism: absence supplies nothing for the model to attend to. The threshold-transfer failure is reported honestly. Benchmark, prompts and judgements are released.
Relevance: Layer 1: summarization, generation, LLM-as-judge. Layer 2: (a) Nuclear Medicine Summarization kit — its item-level binary rubric IS the enumerate-then-check design this paper finds necessary. That is external confirmation of the kit's central choice. (b) Discharge Letter kit — any LLM judge used there to catch omissions is, by this evidence, close to blind unless it is given the list of required facts. (c) The Panel app (LLM-J Monitor) — omission-type rubric criteria need an enumerated fact list, not a holistic check. (d) Prompt_Optimization_Guide.md — prompt optimisation cannot fix a structural blind spot; restructure the task.
Verdict reasoning: Well designed for its question. It identifies a failure mode that matters for every summarization kit here and shows that the usual fixes don't work. Import the method and the mechanism. Quarantine the percentages: constructed benchmark, vendor-affiliated authors, no peer review.

Fox S, Markham L, Lail R, Karotsieris M. One note in three: a verified census of three deployed AI scribes, and the instrument that counted it. arXiv preprint. 2026 Aug 31. arXiv:2608.31017
https://arxiv.org/abs/2608.31017
Overview: Audits three unnamed commercial ambient scribes on the same 142 consultations (recorded UK primary care, US ambulatory, and authored scenarios): 565 notes. Twelve discovery passes proposed 13,678 candidate errors. The 5,898 that cleared an importance filter went to an adversarial panel of two models from different families, each told to refute what it could; 618 survived. Then the paper turns the instrument into the object of study. Same group as PQ-191. Found through the web channel (a secondary write-up on the Pebblous blog) — the arXiv channel was down this cycle. Task type: summarization / documentation — error census · LLM system: 3 commercial scribes; 2-family adversarial review panel · Setting: UK primary care, US ambulatory · Volume: 142 consultations, 565 notes, 618 verified findings · Clinician involvement: physician author (21 findings) and an independent clinician (12), blind, disjoint samples Evidence weight: arXiv preprint. Real recorded consultations, but with no human-written control arm. Very small clinician validation samples.
Eval question: How often do deployed scribes fail — and how much of any published failure rate is the instrument rather than the scribe?
Methodology: • Census with a multi-pass discovery stage and a cross-family adversarial verification panel • Instrument experiments holding model, evidence and settings fixed while varying ONE factor: the review instruction, or the reviewer's model family • Blind, disjoint clinician adjudication of verified findings
Measurement: Share of notes with ≥1 verified failure, with 95% intervals; share of candidates verified under each instrument condition.
Key findings: • 31.3% [27.0–35.6] of notes carry ≥1 verified failure; 24.8% [20.8–29.0] excluding invented identity and dates (a patient record would have prefilled those) • Failures concentrate in allergy and medication information, invented patient identity, and history written up as examination on telephone consultations • A new failure class: a treatment the clinician retracted, recorded as delivered care • Physician author upheld 20/21 findings (95.2% [77.3–99.2]); independent clinician 12/12 ([75.8–100]) • THE REVIEW INSTRUCTION ALONE moves the share of candidates verified from 9.3% to 79.0%; at a fixed instruction, the reviewer's family moves the share of notes flagged from 27.8% to 54.8% • Between 28% and 97% of sampled notes carry a failure, depending on the standard applied • Published audits put omission at 54–86% of errors against 23.1% here — a spread that instrument differences alone can produce • Every reference note in two public corpora (PriMock57, ACI-Bench) carried at least one material discrepancy with its own transcript
Soft spots: No human-written control arm, so it says nothing about scribes vs clinicians. Discovery recall was never measured: 7,780 of 13,678 candidates were dropped by the importance filter and never opened. The products cannot be ranked because their input formats differ. The clinician validation samples are tiny (21 and 12). The omission share is probably an undercount, given PQ-191's own finding. Vendor-of-evaluation-tooling authors.
Strengths: It measures the instrument instead of assuming it. Every factor except one is held fixed in the sensitivity experiments. Verification is cross-family and adversarial, so producer ≠ measurer by construction. All 618 findings, prompts, model versions and the pipeline are released.
Relevance: Layer 1: summarization, generation, LLM-as-judge. Layer 2: KTP #15 (an agreement number is meaningless without its reference standard) gets its strongest evidence yet. PQ-190 showed 0.83 vs 0.51 by aggregation rule; here the review instruction alone swings the verified rate from 9.3% to 79.0%. PQ-186 (the judge's prompt is a design parameter) gets its largest measured effect. For Discharge Letter and Nuclear Medicine: pre-specify the review standard, and report it next to every error rate. PQ-178 (reference provenance): public reference notes are themselves discrepant.
Verdict reasoning: The census is secondary. The instrument experiment is the contribution, and it converges with PQ-190, PQ-193 and the Heidi companion study (paired AI vs clinician notes: 61.0% vs 21.8% error burden depending on detection method). Import the rule 'an error rate is a property of the instrument; report the standard with the rate'. Quarantine 31.3% — the products are unnamed and the rate is not portable.

Bergman H, Liu V, Austin B, Sangera R. Are automated documentation-error judges fit to measure ambient AI scribes? A pre-registered, blinded human-validation study. medRxiv preprint. 2026 Aug 17. doi:10.64898/2026.08.14.26360441
https://doi.org/10.64898/2026.08.14.26360441
Overview: Heidi Health (a scribe vendor; all authors are employees, fully funded by Heidi) validates the automated false-positive screen and severity panel used in its own multi-country AI-vs-clinician note simulation (companion paper: doi 10.64898/2026.08.18.26360701). Ten external GPs, blinded to note authorship, flag source, the pipeline's verdict and severity tier, adjudicated a stratified deterministic sample of 434 flags (236 retained, 198 screened out), 131 of them double-rated. English setting only. Pre-registered; reported per GRRAS. Task type: LLM-as-judge certification · LLM system: 3-stage pipeline (identification, false-positive screen, 3-model severity panel) · Signal type: interpretive (is this span a genuine error?) · Setting: simulated consultations, English · Clinician involvement: 10 external GPs; 565 adjudications Evidence weight: Pre-registered, blinded, external raters. Simulated consultations. Sponsor-built judges validated by the sponsor. Preprint.
Eval question: When no gold standard exists, what does 'validating' an automated judge even mean — and can it license a comparison anyway?
Methodology: • Validation reframed as DEFENSIBILITY, tested as three falsifiable propositions: (A) envelope parity — judge–clinician agreement vs clinician–clinician; (B) non-differential behaviour across the arms being compared (AI vs clinician notes); (C) concordance on clinician-consensus cases • Pre-specified decision rule: unfit if behaviour is differential by arm or systematically diverges from consensus • Forced binary genuineness decision, with no 'uncertain' option • Gwet's AC1 for binary agreement WITH raw agreement; weighted κ plus mean signed difference for severity; Wilson intervals • Sample size set by precision: 131 double-rated items give about an 8-point Wilson half-width on raw inter-clinician agreement • Bayesian latent-class (Hui–Walter) triangulation of the genuine-error prevalence
Measurement: Raw agreement and AC1; kept-precision and removed-confirmed rates by arm; severity signed gap; consensus concordance; latent-class prevalence with a credible interval.
Key findings: • Inter-clinician agreement on genuineness: raw 59% (50–67), AC1 0.24 — there is no human consensus to serve as truth • Judge–clinician agreement 64% (60–68), overlapping the expert envelope • Near-symmetric across arms: kept-precision 74% (AI) vs 81% (clinician); severity signed gap +0.06 vs −0.09 tiers • One asymmetry: removed-confirmed 56% vs 42% — the screen over-removes on clinician notes, which is conservative for the parent study's contrast • Consensus concordance 70% (59–79) on 77 items • The screen's cost: only 48% (42–54) of screened-out flags were confirmed non-errors • Clinicians disagree far more on WHETHER something is an error than on how severe it is • Latent-class genuine-error prevalence 68% (94% CrI 48–83) • Dropping one reviewer (independence attested only by the PI) moved AC1 from 0.24 to 0.13
Soft spots: The sponsor built the judges and ran the validation (mitigated by pre-registration and external blinded raters, not removed). The forced binary depresses agreement. The latent-class model assumes conditional independence, which shared model lineage violates — the authors say so. English only, although the parent study spans five languages. AC1 on 131 items is imprecise and moves with one rater. Data are not public. 'Non-differential' rests on point estimates with overlapping intervals.
Strengths: Pre-registered falsification criteria, stated before the data. AC1 and raw agreement reported together (the S-01/S-05 quartet in practice, minus κ). It reports the one asymmetry that runs against the sponsor. It bounds the error rate instead of point-estimating it, and states the conditions of the non-differential-misclassification argument rather than assuming it.
Relevance: Layer 1: LLM-as-judge; summarization / documentation. Layer 2: (a) The Panel app (LLM-J Monitor) — envelope parity + non-differential across arms + consensus concordance is a usable certification triad for any judge, where 'accuracy' cannot be defined. (b) S-07 (Passonneau & Carpenter) — latent-class modelling is the practical form of 'model the annotation, don't collapse it'. (c) S-01/S-05 — AC1 plus raw agreement at a skewed prevalence, done correctly. (d) Discharge Letter / Nuclear Medicine — pilot the 'is this an error?' question first; it is the hard judgement (AC1 0.24), severity is not. (e) Echoes POPC: disagreement sits at the threshold, not in the attribution.
Verdict reasoning: The framing is the contribution, and it transfers to every judge the kits use. It is honest about its ceiling. Import: the defensibility triad, bounded error rates, and the non-differential-misclassification argument with its conditions. Quarantine every absolute rate: vendor-sponsored, simulated consultations, English only.

Chin AT, Zhu N, Vangala S, Woo H, Wisk LE, Kingsley T, Mafi JN, Lukac PJ. A Pragmatic Randomized Trial of an EHR-Integrated Generative AI Chart Summarization Tool for Ambulatory Clinicians. medRxiv preprint. 2026 Aug 31. doi:10.64898/2026.08.26.26361496
https://doi.org/10.64898/2026.08.26.26361496
Overview: The first RCT of an EHR-embedded generative chart summarizer (Epic Outpatient Insights). 284 outpatient clinicians across 42 specialties at one academic health system were randomised 1:1 to the tool or usual care for 90 days (23 Feb – 23 May 2026). NCT07438743. Task type: summarization (pre-charting) · LLM system: Epic Outpatient Insights (vendor-embedded) · Setting: ambulatory, 42 specialties · Volume: 284 clinicians; 74,474 summaries · Human review: clinicians reviewing summaries in routine work Evidence weight: Randomised and pragmatic, with a prespecified primary outcome. Single system, 90 days, unblinded, primary outcome self-reported.
Eval question: Once a vendor summarizer is actually deployed, what does it deliver — and which endpoint shows it?
Methodology: • Covariate-constrained randomisation, stratified by AI-scribe licence and balanced on baseline task load and chart time • Primary outcome: physician task load (NASA-TLX adapted to pre-charting, 0–400) • Exploratory outcomes: Professional Fulfillment Index, usability, safety reports, EHR time (Caboodle / Signal logs) • Mixed models with arm × period interaction; learning-curve month separated from steady state • Free-text concerns coded qualitatively
Measurement: Adjusted between-arm differences with 95% CIs; engagement from EHR logs; net promoter score.
Key findings: • Of 74,474 summaries generated, only 14.2% were ever interacted with — falling from 21.5% in month 1 to 10.5% in month 3 • Clinicians using it at least once a month: 88.7% → 66.2% • Task load −27.4 (−49.4 to −5.3; P=0.02); burnout −0.20 (−0.38 to −0.01); work exhaustion −0.24 (−0.47 to −0.02) • NO time saving at steady state: −1.2 s per encounter (−19.0 to 16.6) • Net promoter score −22 • 57.1% of free-text respondents reported a concern — including ATTRIBUTION errors (a family member's diagnosis written as the patient's) and STATUS errors (an ordered-but-incomplete action written as done) • No adverse safety events were reported
Soft spots: The primary outcome is self-reported by clinicians who know their arm, so expectation bias is plausible. Exploratory outcomes are not adjusted for multiplicity. Safety was captured only by voluntary reporting, so 'no events reported' is not evidence of safety. With only 14% engagement, the task-load effect is either heavily diluted or partly a participation effect. Ninety days; accuracy never systematically measured.
Strengths: Randomised, pragmatic and prespecified. Engagement decay was measured objectively from logs rather than self-report. It reports the unflattering results — no time saving, a negative net promoter score — alongside the favourable one.
Relevance: Layer 1: summarization. Layer 2: (a) §1 'Adoption is a primary monitoring endpoint' (PQ-184) gains a second independent anchor, and the first that is randomised and in summarization: interaction fell 21.5% → 10.5%, mirroring PQ-184's 68% → 30%. (b) The attribution and status error classes match PQ-192's findings (history written as examination; a retracted treatment written as delivered) — an error taxonomy converging across independent studies. (c) Discharge Letter kit: interaction rate belongs in the monitoring plan. (d) safety_vs_effectiveness.md: 'no safety events reported' under passive reporting says nothing about safety.
Verdict reasoning: A real RCT of the kind the KB rarely gets. Its most important result is the one a benchmark cannot produce: most summaries are never opened. Import the engagement-decay pattern and the error classes. Treat the task-load and burnout effects as fragile (self-reported, unblinded).

Humphries C, Brett J, Gruber F, James E, McKendrick TI, McNairn KC, Miell A, O'Brien R, Rahman F, et al. Half of alcohol, drug, and self-harm presentations cannot be identified in coded emergency department data: a diagnostic accuracy study of a large language model. medRxiv preprint. 2026 Aug 31. doi:10.64898/2026.08.26.26361443
https://doi.org/10.64898/2026.08.26.26361443
Overview: A two-phase diagnostic accuracy study in one UK Type 1 emergency department (adults ≥16). Phase 1, a validation week covering EVERY attendance (n=2,256), compares three strategies — routine clinical coding, blinded clinician review, and a blinded, locally deployed Llama 3.1 70B (temperature 0, no fine-tuning, no retrieval, free text only). Phase 2 applies the LLM to all 105,096 attendances in the year and corrects the prevalence for the LLM's measured error. Task type: classification from notes (3 domains + subdomains) · LLM system: Llama 3.1 70B, local · Signal type: mixed · Setting: emergency department, UK · Prevalence: 12.1% (reference standard) · Volume: 2,256 (validation) / 105,096 (year) · Human review: clinician comparator + senior adjudicator Evidence weight: Unselected single-site population with no spectrum selection; a full year of application. The reference standard has a known structural bias (see soft spots).
Eval question: When routinely coded data are themselves the failing reference, how do you measure both the coding gap and the LLM — and how should the reference standard be built?
Methodology: • Two-phase: validation week on every attendance, then full-year application with error-corrected prevalence • A reliability gate was enforced: two junior raters missed the pre-specified Krippendorff's α ≥ 0.800 (0.795) and were replaced by a more senior clinician • REFERENCE STANDARD: where clinician and LLM agreed, that answer was accepted; only their DISAGREEMENTS went to a senior toxicology-trained EM adjudicator • LLM blinded to clinician outputs and codes; identical prompt across the whole dataset
Measurement: Balanced accuracy, sensitivity and specificity per strategy; paired comparisons; adjusted annual prevalence with CIs.
Key findings: • Reference prevalence 12.1%; coding identified 6.0%, clinicians 10.0%, the LLM 15.6% • LLM vs clinician balanced accuracy: alcohol 0.942 vs 0.930 (p=0.635); drugs 0.959 vs 0.791 (p<0.001); self-harm 0.982 vs 0.908 (p=0.004) • Coding recorded 1.07 domains per identified patient, against 1.32 in the reference — co-occurrence is erased • Across the full year, the LLM identified 14.3% of attendances against 4.1% by coding, in every month • About 12,890 domain involvements a year are not identifiable from coded data • At least 81.6% of self-harm attendances needed medical assessment before psychiatric review
Soft spots: ⚠️ DISCREPANT-RESOLUTION BIAS. Accepting clinician–LLM agreement as truth, and adjudicating only disagreements, means any case where BOTH were wrong is scored as correct. That inflates the apparent accuracy of both tests and makes the LLM-vs-clinician comparison non-independent. The authors acknowledge the reference is 'not fully independent'. The LLM's 15.6% against a 12.1% reference also shows it over-calls. Single site, one model.
Strengths: An unselected population, so no spectrum bias. A pre-specified reliability threshold actually enforced. Full-year application with prevalence corrected for measured error. Local deployment. Coding included as a comparator rather than silently used as truth.
Relevance: Layer 1: classification / extraction from notes; moderate-to-low prevalence. Layer 2: (a) Any kit that uses ICD or coded data as its sampling frame or reference is exposed. Here coding captured about half — directly relevant to POPC and VAP sampling design. (b) rare_events_evaluation.md: 'discrepant resolution' deserves a named anti-pattern — never build the reference standard by adjudicating only where the tests under evaluation disagree; adjudicate a random sample of the concordant cases too. (c) Statistician_Guide.md: correcting prevalence for classifier error is a worked example. (d) KTP #15: the reference standard here was partly constructed FROM the LLM being evaluated.
Verdict reasoning: Promote as a teaching case, not as a performance result. The coding-gap finding is robust (coding played no part in building the reference). Aimyshev T, Arupzhanov I, Zhakhina G, Rakhmankulova A, Smagul S, Gaipov A. Structured extraction from Russian/Kazakh discharge summaries: three model families at the human-agreement ceiling. medRxiv preprint. 2026 Sep 7. doi:10.64898/2026.09.03.26362149
https://doi.org/10.64898/2026.09.03.26362149
Overview: Nazarbayev University, Astana. Stroke discharge summaries in mixed Russian and Kazakh — Kazakh is agglutinative, and 63% of section headers are unique, so no template can be assumed. Three model families under identical inputs: a multilingual BERT-style encoder with CRF heads, a locally fine-tuned Qwen3-4B, and zero-shot GPT-5.5. Three tasks of increasing granularity: section segmentation (4,327 documents), seven-field medication records (708), and dated lab tuples (1,888). All arms share a block-ID representation (extraction as tagging over a fixed segmentation). Task type: extraction (segmentation → entities → full records) · LLM system: encoder+CRF / fine-tuned Qwen3-4B / zero-shot GPT-5.5 · Signal type: explicit · Setting: inpatient stroke, Kazakhstan · Language: Russian / Kazakh · Human review: blind re-annotation of 50 documents per task Evidence weight: Single centre, one condition, preprint. The human ceiling rests on 50 documents per task. Paired same-document tests with Holm correction.
Eval question: How do you claim 'human-level' extraction honestly — and does it hold outside English?
Methodology: • Human-agreement ceiling measured by blind re-annotation of 50 documents per task • Model-vs-ceiling claims tested with paired same-document tests, Holm-corrected • Full-record assembly re-scored SYMMETRICALLY against a blind annotator as a common reference, so models and gold annotators are judged the same way • Identical input representation across all three families
Measurement: Agreement / F1 against the gold standard and against the measured human ceiling.
Key findings: • Section segmentation: every arm within ±0.03 of the 0.905 ceiling (models 0.919–0.932) • Medication detection: the cloud model is above the ceiling (0.966 vs 0.959) • Full-record assembly, scored against a common blind reference: fine-tuned LLM and cloud model 0.344, gold annotators only 0.183 — 'above human' because humans barely agree on the convention • Lab assembly: fine-tuned LLM matches the ceiling (0.898 vs 0.902); the encoder falls far below (0.476) • Residual errors concentrate in annotation conventions the annotators themselves could not agree on • Authors' conclusion: annotation guidelines and task representation, not model capacity, are the binding constraints

Strengths: Every model claim is made against a measured ceiling with paired tests. Symmetric re-scoring against a common reference is exactly the discipline PQ-185-FU says is usually missing. Three families under identical representation, in a non-English and morphologically hard language. It locates the error in the guideline.

Jeong I, Kim Y, Park J-H, Lee H. MISP-Bench: Decomposing User-Provided False Priors into Answer, Rationale, and Guard Effects. medRxiv preprint (v2). 2026 Aug 23. doi:10.64898/2026.05.07.26352627
https://doi.org/10.64898/2026.05.07.26352627
Overview: Decomposes a user-supplied false prior into its parts — the wrong answer the user states, the reason they give, and a 'guard' safety prompt — varying each separately while holding the question and correct answer fixed. 1,724 audited items (1,430 medical multiple-choice, 294 free-form math), 10 open-weight models (1B–27B), 13 prompt conditions. Replicated on two frontier models (GPT-5.6, Gemini-2.5-Pro). Corpus, response records and code released. Task type: medical QA under a user-supplied false prior (sycophancy) · LLM system: 10 open-weight models + 2 frontier replications · Signal type: explicit (multiple-choice key) · Setting: benchmark, not a clinical workflow · Human review: a six-category item audit removed 770 flawed source items Evidence weight: Benchmark study with a factorial design. Mostly small open models. No clinical workflow and no clinician adjudication. v2 preprint.
Eval question: When a user states a wrong belief, which part of it causes the harm — and does a 'verify first' guard prompt actually help?
Methodology: • Factorial manipulation: wrong answer, wrong rationale, and guard prompt varied separately • The 'error-prone option' is identified by a strong reference model • Within-model reasoning-budget sweep • Frontier replication; distractors regenerated with a different model as a robustness check
Measurement: Accuracy drop; adoption rate of the user's wrong answer; interaction (additivity) tests across models.
Key findings: • Wrong answer plus wrong rationale do LESS damage than the sum of each alone (sub-additive on 7 of 10 models) • The popular guard prompt 'verify the reasoning first' splits models into recovery, no-effect and reversal groups — it made outcomes WORSE on 4 of 10; the split tracks reasoning capacity • Models adopt the user's wrong answer 78% of the time when it matches an option the model itself tends to get wrong, but only 39% when it does not — two attacks with the same accuracy drop, very different behaviour • Model size explains none of these effects in the 1B–27B range • The findings replicate on two frontier models and survive regenerating the distractors • The source-item audit removed 770 flawed items, 732 of them multi-answer items that single-best-answer scoring cannot handle
Soft spots: Multiple-choice and math, not clinical decisions. Mostly small open models. Defining 'error-prone' with a reference model is partly circular. No clinician involvement. The code repository is anonymised.
Strengths: The factorial decomposition turns 'sycophancy' into separable, testable parts. It tests a widely recommended guard prompt and finds it can reverse. Everything is released. A frontier replication was run. The item audit is itself a warning about benchmark quality.
Relevance: Layer 1: conversational / decision support; prompt optimisation. Layer 2: (a) The OPEN PQ-174 vs PQ-153 contradiction. This suggests a mechanism under which both can be true: a wrong prior collapses performance when it coincides with the model's own error-prone option (78%), and much less otherwise (39%). See the flagged contradiction in this email. (b) Prompt_Optimization_Guide.md: a generic safety instruction can reverse on some models, so test guard prompts per model, never assume them. (c) Evaluations should report HOW a model fails (adoption), not only the accuracy lost.
Verdict reasoning: Not clinical, so it cannot settle a clinical question. But it offers the first concrete, testable mechanism for a contradiction that has been open for five cycles, and the guard-prompt reversal is directly usable. Import it as a hypothesis for KTP #9, not as evidence.
